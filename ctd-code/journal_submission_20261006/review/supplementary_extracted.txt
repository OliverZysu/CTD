Supplementary information
Graph-based exploration of chemical–disease associations with literature and gene-context
evidence
This document records the evidence basis of the exploratory manuscript and specifies a prospective
evaluation design. Reported historical outcomes, direct descriptive reanalysis and future experiments are
identified separately. No model training, new literature-screening experiment or new gene-path computation
was performed in preparing this analysis.

S2
Model configuration and reproducibility limits
Table S2 describes the retained GraphSAGE source. Training and validation are full-graph encodings of
the same training-positive edge set, followed by pair classification on each split. No explicit neighborhood
sampler is used in this GraphSAGE entry point. Although GraphSAGE supports inductive applications,
this implementation uses learned node identities and does not supply features for an unseen chemical or
disease.

fails static parsing because of an indentation error. The two available GAT logs terminate with a missing
torch_geometric dependency and contain no numerical epoch metrics. The original CTD and
environmental input paths are absent. These observations prevent the current source collection from serving
as a single verified reproduction environment. They do not establish that the earlier experiments were never
run.
Weight-file metadata further indicates different task configurations: the retained GraphSAGE embedding
has 25,018 nodes and a two-class output, the final GAT embedding has 728 nodes and two classes, and two
other GAT weights have 13,942 nodes and three classes. These metadata were inspected without executing
the serialized models. Weight files with different node counts and output classes cannot be treated as
matched model-comparison results without their own input mappings and run manifests.
S3
Literature-screening aggregates
Table S3 contains the expanded-window rates. Counts in the third column are reconstructed from the
printed percentages and a stated denominator of 1,000; they are not a substitute for individual literature
judgments. For the first six windows, support decreases as numerical rank increases. Thus a Spearman
coefficient computed against numerical rank would be negative; a positive sign would refer to a decreasing
score axis. The manuscript omits the ambiguous correlation annotation in the source chart and reports the
observed sequence directly.

The evidence record proposed for a future system includes: chemical and disease identifiers; original

match and scientific support for the asserted relation should be separate fields.
S6
Prospective evaluation specification
This section is a proposed research protocol. It supplies no completed experiment results.
Dataset freezing and identity. Save source release/date, license, checksum and extraction criteria.
Resolve chemicals with explicit namespaces and retain mixtures or classes without forcing a molecular
identity. Resolve diseases to supported ontology identifiers. Preserve source-level rows but construct model
splits from unique identifier pairs and typed relations. Record uncertain mappings and report their coverage.
Labels and candidate universe.
Separate therapeutic, adverse-event, exposure-association,
marker/mechanism and inferred relationships. Use a declared binary task only when the collapsed
meaning is appropriate. Label absent pairs as unobserved; document negative sampling and evaluate
sensitivity to its choice. Export all positive-class candidate scores outside the frozen known-pair set, with y,
ˆy, score vector, split, entity IDs, pair ID, snapshot and run ID.
Splits and leakage checks. Publish unique-pair train/validation/test manifests. Require zero held-out
pair overlap with training labels and message-passing edges, including reverse-edge and source-alias checks.
Where gene-mediated edges derive from target associations, check target-dependent inference leakage.
Assess transductive random, chemical-disjoint, disease-disjoint and temporal splits as distinct settings.
Specify how unseen nodes are represented before interpreting disjoint evaluations.
Comparators and metrics. Compare degree-based scores, an embedding MLP and graph baselines on
identical splits. Include a disease-association-specific method such as LAGCN or MRDDA when its inputs
and implementation can be made comparable. Predefine tuning budgets and at least five independently
seeded runs as a practical project target. Report AUROC, average precision, precision at fixed review
budgets and calibration. Use paired comparisons and uncertainty estimates appropriate to repeated entities;
disclose how prevalence in the test set differs from the application candidate space.

Literature validation. Freeze the prediction list before searching. Record query strings, date, retrieval
system, model version if used, and retained bibliographic identifiers. Use an explicit rubric: direct relation
support; indirect/contextual support; therapeutic relation; contradictory result; co-mention only; or no
eligible evidence. Obtain independent judgments and adjudicate disagreement. Separate pre-cutoff literature
from later evidence and remove articles used to construct training labels from any independent-validation
count. Compare uniform and degree-/literature-matched controls using the same retrieval budget.
Gene contribution. Compare chemical–disease-only models with typed gene-augmented models, a
shuffled-gene control and degree-aware baselines. Report mapping coverage and shared-path rate separately.
Keep each path’s two source edges and evidence IDs. Evaluate whether gene information improves held-
out prediction and whether it yields useful explanations as different endpoints. Repeat the disease-label
permutation and save every replicate rate before drawing enrichment conclusions.
System evaluation. Select a reproducible set of queries and candidate records. Measure exact entity
resolution, article-link resolution and source-passage correctness. Check PubMed/DOI and Acemap links
independently. Evaluate representative end-to-end user tasks and report the tested version. Availability of a
homepage is insufficient evidence of a functioning literature or prediction service.
