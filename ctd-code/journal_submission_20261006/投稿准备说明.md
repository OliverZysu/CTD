# 投稿准备说明

推荐首选 **Journal of Cheminformatics**，按研究论文（Research）方向推进。当前成果最合适的定位是：**化合物—疾病关联筛选、文献证据追溯与基因解释线索的探索性研究**。建议英文题目为 *Graph-based exploration of chemical–disease associations with literature and gene-context evidence*。

本轮已完成英文论文初稿、补充材料、矢量图、可编辑 LaTeX、双倍行距且带连续行号的审稿排版版，以及材料核查。作者、单位、通讯邮箱和尚未确认的声明均按要求留空。当前文件可用于组内讨论与定稿；由于原始实验和验证材料缺失，不能把它当作已经满足正式投稿条件的终稿。本轮没有向期刊提交材料。

最终分页：英文正文 12 页；带行号审稿版 17 页；补充材料 5 页。全部 PDF 使用嵌入字体，未发现缺失引用、越界文字或 Type 3 位图字体。

## 为什么推荐 Journal of Cheminformatics

该刊范围包含化学信息系统、软件、数据库和数据挖掘，与本项目从污染物扩展到一般化合物、组织疾病关联并追溯证据的方向匹配。现阶段的主要价值应从可复现的数据与验证流程中建立，不能把现成 GNN 基线包装成新算法。

| 期刊 | 对当前项目的建议 |
|---|---|
| **Journal of Cheminformatics** | 首选；完善数据规范、关联筛选、对照实验和证据链后投稿 |
| **Bioinformatics** | 当有明确算法增量，或形成可维护且有广泛用途的软件工具时考虑 |
| **PLOS Computational Biology** | 当计算分析带来实质生物学新认识时考虑；不应把湿实验误写为所有稿件的统一硬性要求 |
| **Patterns** | 当数据资源或研究流程具有跨领域复用价值时考虑 |

核查日期为 2026-10-06。Journal of Cheminformatics 的通用指南经官方页面的文本渲染读取，要求双倍行距、行号、页码和可编辑源文件，并要求数据/材料可用性声明。Research 专属摘要限制未成功取得，未冒称已逐条符合该刊最新版模板。Bioinformatics、Patterns 的部分页面受到访问验证限制。具体核验方式、来源和访问限制见 `evidence/journal_and_references.md`。

## 正式投稿前最需要补齐的工作

以下是本项目已发现问题对应的研究工作，不是额外审批流程，也不是声称期刊对所有论文都要求这些实验。

1. **恢复数据和实验对应关系。** 找回实际使用的 CTD CSV、环境 JSON、基因源文件、下载日期和训练配置，保存 SHA256；明确每个权重、结果表、候选文件属于哪次运行。当前目录内的两份训练日志只有依赖导入失败，没有训练指标。
2. **修正候选导出。** 保存化合物/疾病稳定 ID、真实标签、预测类别、完整类别分数、已知边状态、split、run_id；从冻结数据集之外的候选对按正类分数排序。原来按误分类置信度排序的表可以用于错误分析。
3. **完成可复现的同口径比较。** 先按唯一 pair 划分，检查重复样本、正反向边和推断关系泄漏；修复现有代码的返回值不匹配、语法和依赖问题。至少覆盖 MLP、度基线和主要 GNN，报告多随机种子、不确定性及 PR 类指标。具体前瞻方案在补充材料 S6，尚未运行。
4. **重做可审计的文献验证。** 固定候选列表和时间界限，保留逐条检索及判断；区分直接支持、间接线索、治疗、共现、矛盾和无证据。训练已用文献不能同时算独立验证。至少加入匹配节点度或文献数量的对照，并进行独立判读。
5. **检验基因层实际增益。** 分别评价“预测是否改善”和“解释是否有帮助”；保存全部置换结果、映射失败原因及边的来源。当前 12.8% 对 18.7% 不能用于声称机制富集。
6. **完成公开复现与声明。** 按许可提供可分发数据、处理脚本、环境版本、代码许可证和可引用仓库；本地路径不是公开数据地址。补齐作者、贡献、基金、利益冲突和适用伦理声明。原训练脚本含凭据字段，未纳入交付包；发布源码前需清理并妥善处置该凭据。

没有原始数据时，不能通过补写方法文字、重新绘图或增加参考文献替代这些证据。现有 PDF 已把此边界说明清楚。
